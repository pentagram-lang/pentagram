# Review

Within [quality](../README.md), code review gives a named set of code surfaces an independent, unsteered inspection. A reviewer with no inherited authoring conversation or project conclusions inspects the code as written against code criteria and reports every supported problem that keeps it from being clearly correct.

Review separates the author's orchestration from the reviewer's inspection so that independence stays intact across handoffs, evaluation, and repair. Mixing author decisions or repair arguments into the reviewer's instructions would steer the inspection and weaken the resulting evidence.

## Workflow

[Review workflow](workflow.md) guides the author through deciding when review adds evidence, preparing the handoff, evaluating findings, and arranging re-reviews.

## Protocol

[Review protocol](protocol.md) tells the reviewer how to inspect named code surfaces as written and report every supported problem without proposing repairs.
